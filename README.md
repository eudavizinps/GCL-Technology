## O projeto

Site institucional da GCL Technology. A página organiza as soluções da empresa, apresenta serviços e capacidades e oferece caminhos diretos para contato.

## O que você encontra

- Apresentação das soluções e dos serviços
- Seções sobre a empresa, suas capacidades e seu processo
- Navegação responsiva e chamadas para contato

## Tecnologias

HTML, CSS e JavaScript, com arquivos separados por seções e ajustes de responsividade.

## Executar localmente

Abra `index.html` em um navegador. Não há etapa de compilação.
